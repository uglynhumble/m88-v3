# М88 — сайт на два раздела

Два лендинга на одном домене, заявки уходят прямо с сайта (почтовая программа не открывается).

```
/                     главная — инжиниринг и нестандартное оборудование
/press-formy/         пресс-формы из Китая под ключ
/send.php             приём заявок с обеих форм
/config.php           ← единственный файл, который нужно отредактировать
```

---

## Запуск за 4 шага

### 1. Залейте файлы

Всё содержимое этой папки — в корень сайта (`public_html`, `www` или `httpdocs`).
Структуру папок сохраните как есть.

### 2. Откройте `config.php` и проверьте два поля

```php
'to'   => 'zakaz@m88.su',    // куда приходят заявки (можно несколько через запятую)
'from' => 'noreply@m88.su',  // от кого уходит письмо
```

**Важно:** адрес в `from` должен существовать на вашем домене. Заведите на хостинге
ящик или алиас `noreply@m88.su` — иначе почтовые сервисы посчитают письма подделкой
и отправят в спам.

### 3. Дайте права на папку `storage`

Права `755`. В неё пишется журнал `leads.csv` — все заявки дублируются туда
на случай проблем с почтой. Из браузера папка закрыта.

### 4. Отправьте тестовую заявку

Заполните форму на сайте и убедитесь, что письмо пришло. Если не пришло —
смотрите раздел «Если письма не доходят».

## Проверьте лимиты загрузки

Чтобы к заявке проходили вложения до 20 МБ, на сервере нужны значения:

| Параметр | Значение |
|---|---|
| `upload_max_filesize` | 21M |
| `post_max_size` | 25M |
| `max_file_uploads` | 10 |

Файл `.user.ini` в корне уже выставляет их — на большинстве хостингов этого хватает
(изменения подхватываются в течение 5 минут). Если хостинг его игнорирует,
задайте те же значения в панели управления, в разделе настроек PHP.

Проверить, что применилось: временно положите в корень файл с `<?php phpinfo();`,
откройте его в браузере, найдите `upload_max_filesize`, **потом удалите файл**.

## Если письма не доходят

Причина почти всегда одна: хостинг отправляет через `mail()`, а почтовый сервер
получателя не доверяет такому письму. Решение — отправлять через SMTP вашего ящика.
В `config.php`:

```php
'smtp_enabled' => true,
'smtp_host'    => 'smtp.yandex.ru',   // или smtp.mail.ru, smtp.gmail.com
'smtp_port'    => 465,
'smtp_secure'  => 'ssl',              // 'ssl' для 465, 'tls' для 587
'smtp_user'    => 'noreply@m88.su',
'smtp_pass'    => 'пароль приложения',
```

Для Яндекса и Mail.ru нужен **пароль приложения**, а не обычный пароль от ящика —
он создаётся в настройках безопасности почты.

Дополнительно стоит попросить хостинг настроить для домена записи **SPF, DKIM и DMARC** —
без них любые письма с сайта регулярно попадают в спам.

## Дублирование заявок в Telegram (по желанию)

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. Добавьте бота в рабочий чат и напишите туда любое сообщение.
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `chat.id`.
4. Впишите оба значения в `config.php`.

Заявка придёт и на почту, и в чат.

## Что где лежит

| Файл | Зачем |
|---|---|
| `index.html` | главная страница, стили внутри файла |
| `press-formy/index.html` + `styles.css` | страница пресс-форм |
| `assets/form.js` | отправка обеих форм, вложения, экран «отправлено» |
| `assets/form.css` | стили статусов, чипсов файлов и экрана «отправлено» |
| `send.php` | приём заявки, письмо с вложениями, журнал, Telegram |
| `config.php` | все настройки |
| `.htaccess` | HTTPS, редиректы, кэш, сжатие, защита служебных файлов |
| `nginx.conf.example` | то же самое, если сервер на nginx без Apache |
| `storage/leads.csv` | журнал заявок, открывается в Excel |
| `404.html` | страница «не найдено» |
| `robots.txt`, `sitemap.xml` | для поисковиков |

**Домен.** В `.htaccess`, `robots.txt`, `sitemap.xml` и в `<link rel="canonical">`
обеих страниц указан `m88.su`. Если домен другой — замените его в этих файлах.

## Форма обратной связи

На обеих страницах форма одна и та же — одинаковый набор полей, подписи, зона
вложений и кнопка **ОТПРАВИТЬ ТЗ**. Разметка и стили общие (`assets/form.css`
и `assets/form.js`), так что правка в одном месте меняет обе страницы.

Поля: Имя\*, Компания, Телефон\*, E-mail, Должность, Задача / описание ТЗ, вложения.

**Телефон.** При клике в пустое поле подставляется `+7 (`, дальше цифры сами
раскладываются в `+7 (999) 123-45-67`. Номер, вставленный как `8 495 1234567`
или `+7 495 …`, приводится к тому же виду. Если человек начинает с `+` и другого
кода страны (например `+86` — Китай), маска не вмешивается: у М88 есть зарубежные
контрагенты. Неполный российский номер форма отправить не даст — проверка есть
и в браузере, и на сервере; в письме и в журнале номер всегда в едином формате.

## Как это работает

Посетитель заполняет форму → браузер отправляет данные и файлы на `send.php`
без перезагрузки страницы → PHP проверяет их, собирает письмо с вложениями
и отправляет на `zakaz@m88.su` → на месте формы появляется «Заявка отправлена»
с номером обращения.

Защита от спама работает без капчи: скрытое поле-ловушка для ботов, проверка
скорости заполнения, ограничение 5 отправленных заявок в час с одного IP.
Ошибочные попытки в лимит не засчитываются — человек, опечатавшийся в поле,
не окажется заблокирован.

Ограничения вложений: до 5 файлов, суммарно 20 МБ, форматы PDF, DWG, DXF, STEP,
STL, IGES, X\_T, SLDPRT, SLDASM, ZIP, RAR, 7Z, JPG, PNG, DOC, XLS.
Меняются в `config.php` (сервер) и в начале `assets/form.js` (браузер) — держите
значения одинаковыми.

## Цели для аналитики

Скрипт формы сам сообщает об успешной отправке:

- **Google Tag Manager / GA4** — событие `form_success` в `dataLayer`.
- **Яндекс.Метрика** — цель `form_success`. Чтобы заработала, добавьте перед
  подключением `form.js` строку с номером счётчика:
  ```html
  <script>window.M88_YM_ID = 12345678;</script>
  ```

## Проверено

- **Браузеры:** Chrome, Edge, Opera, Яндекс.Браузер (Chromium), Firefox, Safari.
  Код формы написан на ES5 — работает в Safari 9+, iOS 9+, Android 5+.
- **Экраны:** 1440, 1280, 834 (планшет), 412 (Android), 390 и 375 (iPhone), 320 —
  горизонтальной прокрутки нет нигде.
- **Разметка:** обе страницы проходят валидацию HTML5, дублирующихся `id` нет,
  битых ссылок и якорей нет.
- **Без JavaScript** страницы отображаются полностью (раньше контент оставался
  невидимым) — важно для поисковых роботов и корпоративных браузеров с ограничениями.
- **Отправка формы** проверена на десктопе и на мобильном: вложения, удаление файла,
  экран «отправлено», повторная отправка, все сообщения об ошибках.
- **Маска телефона** проверена на наборе по цифре, вставке номеров в форматах
  `8…`, `+7…` и `+86…`, удалении через Backspace и на отказе отправить неполный номер.
- **Формы на двух страницах** совпадают по набору полей, подписям и кнопке —
  сверено автоматически.
